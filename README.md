# Kindly Bot Playground

Construir uma aplicação web completa de Chatbot com Inteligência Artificial:

- Interface de chat moderna, responsiva e intuitiva (mensagens com visual fluido, sugestões rápidas e suporte a markdown)
- Inteligência Artificial para gerar respostas naturais, contextualizadas e inteligentes
- Painel de personalização:
  - Nome do bot e avatar
  - Personalidade e tom de voz (formal, descontraído, especialista, etc.)
  - Informações da empresa e instruções personalizadas
  - Base de conhecimento (perguntas frequentes, regras de atendimento e contexto do negócio)
- Recursos profissionais:
  - Histórico de conversas salvo por sessão
  - Criação de novas conversas e exclusão de histórico
  - Modo de teste e pré-visualização de como o cliente final verá o chat
  - Link de compartilhamento público para atendimento aos clientes
